# CIS261_WK10_VIBE

## Student Grade Calculator

This program uses **Option B: a `Student` class**. Each object stores the
student's name, ID, three test scores, calculated average, and letter grade.

Run it with:

```text
python VIBE.py
```

Records are loaded from and saved to `student_grades.txt`. Press `ESC` at the
main menu, or while entering a record, to exit or return to the menu.
